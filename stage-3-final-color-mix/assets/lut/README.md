# Technical LUT

本目錄放置 Stage 3 可用的 Technical LUT。

指定檔案：

- `DJI OSMO Pocket 4P D-Log2 to Rec.709 V1.0 size65.cube`
  - 僅限已可靠確認為 D-Log2 的素材。

- `DJI OSMO Pocket 4P D-Log to Rec.709 V2.0 size33.cube`
  - 僅限已可靠確認為 D-Log 的素材。

禁止因素材來自 DJI / OSMO Pocket 就直接套 LUT；`color_profile=unknown` 時不得使用。詳細規則以本階段 `PROMPT.md` 為準。
